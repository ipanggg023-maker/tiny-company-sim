# 🏢 บริษัทจิ๋ว — Tiny Company Sim

เกมบริหารบริษัทเล็กๆ ในเบราว์เซอร์ ที่พนักงานทุกคนมีนิสัย อารมณ์ และความสัมพันธ์ของตัวเอง — เรื่องราวเกิดขึ้นเองจากระบบ

**▶ เล่นเลย: https://ipanggg023-maker.github.io/tiny-company-sim/**

## จุดเด่น
- ออฟฟิศ 2.5D แบบ isometric พร้อมตัวละคร low-poly ที่สร้างจากโค้ด ช่วงกลางวัน/กลางคืน แสงไฟเรืองแสง
- พนักงานเดินไปชงกาแฟ คุยกับเพื่อนสนิท จ้องคู่กัด หลับคาโต๊ะ
- รับงานลูกค้า เก็บมัดจำ ส่งให้ทันเดดไลน์ เปิดแผนกใหม่ ขยายออฟฟิศ
- เหตุการณ์ให้ตัดสินใจ: ขอขึ้นเงินเดือน คู่แข่งมาซื้อตัว ทะเลาะกันหนัก
- เสียงประกอบสังเคราะห์ในเบราว์เซอร์ เซฟอัตโนมัติ

## รันเอง
```bash
py -m http.server 8123
```
แล้วเปิด http://localhost:8123 (ต้องใช้ http ไม่ใช่ file://)

ทดสอบสมดุลเกม: `node tools/balance-sim.js 300 365 smart`
